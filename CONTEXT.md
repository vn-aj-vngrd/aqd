# Domain language

Use these terms in code, docs and UI. V1 is one private device; V2 terms are marked.

| Term | Meaning |
| --- | --- |
| Closet | A person's owned wardrobe: pieces, outfits, themes. |
| Piece | One owned clothing, footwear or accessory item with a cover photo and optional metadata. A photo is media, not the piece. Category: Tops, Bottoms, Dresses, Layers, Shoes, Accessories. |
| Outfit | A saved combination of owned pieces. A generated combination is a draft until saved. |
| Theme | A named, reusable collection of outfits by mood, style or occasion. Independent of dates. |
| Draft | A proposed piece, outfit, theme or plan not yet saved or applied. |
| Plan / plan entry | A named set of dated outfit intentions / one outfit for a date and occasion (unassigned, planned, worn, skipped). |
| Event, routine | A bounded occasion such as a trip / a repeating context such as weekday office wear. Both can own a plan. |
| Wear record | Pieces actually worn on a day. Plans and saved outfits never imply wear. |
| Today | First destination: a personal stack of in-app cards (not system widgets). |
| Planner | Calendar workspace for plans, routines, trips and packing. |
| Agent | Conversational assistant over authorized local context; every change is a reviewed draft. |
| Change set | One review of related changes the Agent prepared, such as archiving several pieces. Rows can be unticked; only ticked rows apply. |
| Receipt | The acknowledged record of an applied change. It can offer Undo while the record is unchanged since. |
| Fit memory | Private dated journal entry in Profile: a photo and/or linked outfit snapshot plus a note. Not wear. |
| Local profile | Optional name, photo, caption and style preferences on this device. Not an account. |
| Insight | An observation with a stated basis, window and denominator. |
| Local archive | User-initiated versioned export for manual restore. Not sync. |
| Profile, post, feed, bookmark, Inbox (V2) | Connected social identity, published presentation, public discovery, saved public content, human chat. |
