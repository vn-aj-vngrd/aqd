- Existing iOS **26.5**, build **23F77**, `iPhoneSimulator26.5.sdk`; existing iPhone **17 Pro** simulator, compact portrait. No SDK/runtime was installed.
- Every new PNG is an unmodified `xcrun simctl io … screenshot`: **1206 × 2622 px**, representing **402 × 874 pt @3x**. No crop, repaint, recompression or post-capture text replacement.
- The 390 × 844 Paper caller underlay is uniformly scaled into the runtime using `min(402/390, 874/844) = 1.0307692308`, producing 402 × 869.9692 pt with a 2.0154 pt vertical inset. Source-control rectangles use that same mapping.
