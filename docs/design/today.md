## Action, commit and return checklist

- Customize → TW02 copied draft; clean Back restores trigger/scroll without writing; dirty Back → TW13.
- Add → TW03 → type configuration. Nested Apply updates parent only. Back/cancel retains previous parent content and protects only nested dirty edits.
- Widget-editor instance rows are passive label/current-value metadata with one44-point trailing native More action → TW10; Edit/Configure there opens the instance editor/source chooser. Do not treat passive metadata as a second hidden configuration button. Real standalone picker/configuration disclosures retain their fixed22-point chevron and whole-row target. Source task return preserves instanceID, layout draft, selection and scroll.
- Remove checks minimum one before mutation; refusal restores row focus. Reorder supports drag and labelled Move up/down, keyboard and VoiceOver position; boundary moves are disabled.
- Restore → TW14 provisional stock three; Undo restores exact prior draft. Existing records and personal content stay retained; no automatic deletion of Photos.
- Done revalidates all instances/media/revision, commits one operation atomically. Pending disables mutation/duplicate save; acknowledged result alone updates layout/Undo. Failed preserves draft/previous layout; unknown reconciles operation before retry.
- Dirty discard is routine, source-anchored, no-write safe dismissal/Keep editing. Critical substantial-loss alert is reserved for the existing risk contract, never for every widget edit.
- Weather opens existing shared setup/details with actual caller return; adding/opening does not consent/enable. Public Search remains All/Following-only, private personal data excluded.
