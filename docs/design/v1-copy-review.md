# V1 copy review — complete pre-overlay ledger

## Scope and timing

This is the completed **pre-confirmation-overlay** copy/layout pass on [Paper · 01 · V1](https://app.paper.design/file/01M3SM2KBHBZG6MA0Q744Y9NW0/p-2-0). It records every finding and occurrence from the copy worker, not a new Paper scan. Later native confirmation overlays may supersede visible confirmation labels or hide headers; the historical old/new ledger must not be interpreted as an all-current-exact-node assertion after those overlays. Independent reviewer **b5cb completed PASS**: all 93 finding groups, 107 occurrences and 76 root contexts were examined, with consequential contracts read in full and no confirmed semantic regressions. No native/runtime certification is claimed.

The [portable JSON evidence](evidence/v1-copy-review.json) contains the full occurrence fix ledger, deduplicated mapping, source root/text IDs, measured impacts, layout fixes, coverage and retention summary. It is self-contained; transient `/tmp` exports are provenance, not a required dependency. Links below open the verified V1 page; each linked root name includes its canonical screen ID and exact Paper root ID for locating it on the canvas. They are not invented app routes.

## Coverage and impact

- Reviewed **183 roots: 169 canonical + 14 reference**, **2,366 text occurrences / 1,001 unique strings**. Reference-root annotations are excluded from app-copy findings; embedded examples were reviewed separately.
- **93 deduplicated finding groups / 107 text occurrences**: **63 rewritten**, **44 redundant text nodes removed**, across **76 canonical screens**. **3 empty introduction groups** were hidden to remove residual flow gaps, without deleting group identity.
- Copy-pass roots remained **183 → 183**; canonical count remained **169** and original screen/root IDs were preserved. V1 nodes changed **9,709 → 9,665 (−44)**, solely the recorded text deletions. These are copy-pass bounds/counts, not post-overlay totals.
- No font shrinking, type-role changes or reduced control targets. Measured action controls retain at least 44-point bounds; intrinsic action text may become narrower without shrinking the containing control.

Measured bounds below are actual Paper `get_node_info` values at the 390-point reference viewport, not estimates. **T** = text width×height; **P** = parent width×height, in points. `removed` means deleted text; `unmeasured/hidden` means null dimensions, not a measured zero. Shared parent deltas overlap across siblings and **must not be added together**. All per-occurrence character counts, measured bounds and source style evidence are preserved in JSON.
