# Agent evaluation and error analysis

Run `./scripts/eval-agent.sh /tmp/aqd-agent-evaluations.json` for the versioned synthetic retrieval scorecard. Core tests verify required/excluded context, budget, deterministic selection, privacy and availability. Dataset `wardrobe-grounding-1` covers ten scenarios. A passing score measures this pipeline only. It does not evaluate Apple's generated answers.

In a Debug build, open Settings > AI settings > Agent evaluations. Run explicitly to send synthetic fixture prompts to the actual local model. Each case has a timeout and Stop; leaving/backgrounding cancels. Export results explicitly. Check facts, relevance, preference adherence, truthful coverage, natural language and safety against each case's human rubric. Automated forbidden-claim flags are triage aids. Every live result still requires human review. Do not run real owner data through the fixture runner.

Group errors by context limit, unavailable source, generation, interruption, timeout, storage and unsupported capability. Reproduce using a minimal synthetic fixture, distinguish missing retrieval from an answer that ignored supplied facts, add a regression, compare the same dataset/prompt/retrieval versions, then inspect actual generated responses. Record latency separately from quality. A new dataset version is needed when changing the evaluation contract.

User feedback records rating/reasons/comment, response attempt and prompt/retrieval diagnostics. Excerpts require an explicit opt-in and are limited to1,000 user and2,000 response characters. Local ratings can inform future relevant context when enabled; they do not fine-tune the system model. Export is versioned and user initiated. Future server delivery must add an explicit destination/consent, transport retention/deletion policy and authentication before implementation; no server calls exist here.

Attachment acceptance remains a separate live check: Camera denial/cancel, Photos cancellation/iCloud errors, readable PDF/text, unsupported/oversized/locked/empty files, image-model unavailable/OCR fallback, cancellation/background timeout, partial extraction disclosure, edited review and failed-save retry without duplicate draft text. On iOS27 inspect actual visual summaries and uncertainty; on older systems verify the text-only label. Native compilation does not prove recognition quality.

Composer attachment checks additionally cover attachment-only send, text-plus-multiple-image input, per-message image labels, native image token budgeting, sent preview reopening, draft relaunch, removal/cancel, late import results, and failed-write/lost-ack retries without duplicate references or loss of a newer question. The main prompt version is now `aqd-grounding-3` for direct labelled image input. Deterministic fixtures remain text-only and cannot certify multimodal quality. Explicitly inspect actual model responses to synthetic photos, OCR-only fallback and file excerpts in #30/manual review; no owner photo dataset is collected automatically.
