# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs evaluation |
| needs-info | needs-info | Waiting on missing information |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human judgment/access |
| wontfix | wontfix | Declined or already satisfied |

Triaged issues have one state and one category, `bug` or `enhancement`. Replace the previous state when changing it; read existing context before overriding another maintainer's state. Follow the triage skill's disclosure requirement when publishing AI triage notes.
